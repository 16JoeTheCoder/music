# Still design system
Mode: Operate. A quiet record-library workspace with warm paper surfaces, dark ink, forest green active controls, and restrained outlines. The library is the first viewport; empty states replace invented content. Desktop navigation sits beside the library; mobile navigation and the persistent player remain reachable.

The implemented palette uses paper `#f7f6f0`, ink `#252d26`, forest green `#365644`, and a `#648873` focus outline. Self-hosted DM Sans is the primary typeface, with DM Serif Display for display headings. The interface uses semantic buttons, labeled native range controls, focus indicators, and actionable errors. Coarse-pointer player and track actions target 44px; the mobile player stacks its controls beneath the current track. Smaller text and other control targets still need accessibility validation.

Primary workflow: upload → find track → play → optionally keep offline on this device. Metadata editing, playlist management, and destructive confirmation preserve task context. Download completion is shown only after durable storage commits. The player remains mounted during navigation.
